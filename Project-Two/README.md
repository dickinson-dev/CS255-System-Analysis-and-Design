# Project Two: System Design Document

This artifact translates the approved DriverPass requirements into a technical system design. It contains a use case diagram, two activity diagrams, a sequence diagram, and a class diagram that describe the system from functional, behavioral, and structural perspectives.

The supporting technical requirements address cloud-hosted hardware, browser-based software, development and support tools, system availability, performance, security, third-party services, backups, monitoring, and future capacity planning.
